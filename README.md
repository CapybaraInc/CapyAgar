# 🦫 CapyAgar — Апельсиновое безумие

**Многопользовательская io-игра:** ты капибара, ешь апельсины и других игроков, чтобы стать самым большим зверем на карте!

[![Play](https://img.shields.io/badge/🎮-Играть_онлайн-brightgreen)](https://твой-username.github.io/CapyAgar/)
[![License](https://img.shields.io/badge/License-MIT-blue)](LICENSE)

---

## 🎮 Геймплей

- 🦫 Ты — **капибара** с апельсином на голове
- 🍊 Собирай апельсины — становишься больше
- 🐺 Ешь ботов и других игроков (если ты крупнее)
- 🏆 Таблица лидеров в реальном времени
- 📱 Работает на телефоне и ПК

## 🕹️ Управление

| Устройство | Действие |
|-----------|----------|
| 🖱️ ПК | Двигай мышью |
| 📱 Телефон | Води пальцем по экрану |
